# Tab Switcher Extreme

<!-- Plugin description -->
Open files quickly by organizing them in separate lists.

The lists are defined in **Settings | Tools | Tab Switcher Extreme** by specifying regex patterns for their (full) file names, one list per line. For example:

- `.*xml` for files ending with `.xml`
- `.*Activity_.*` for files with `Activity_` in their name

Any file that is not matched by any of the patterns is placed in an extra list named "Other".

The switcher is bound to <kbd>Alt+A</kbd> by default. You can rebind it, for example to <kbd>Ctrl+Tab</kbd>, where the standard switcher lives.

Usage: hold <kbd>Alt</kbd> and press <kbd>A</kbd> to open the switcher. Keep holding <kbd>Alt</kbd> while you move the selection with the arrow keys, <kbd>Page Up</kbd> and <kbd>Page Down</kbd>. Press <kbd>A</kbd> repeatedly to cycle through older files, or add <kbd>Shift</kbd> to cycle through newer ones.

Based on the original [TabSwitch plugin](https://github.com/BasLeijdekkers/TabSwitch) by Bas Leijdekkers and on [TabSwitcherExtreme](https://github.com/xorgate/TabSwitcherExtreme).
